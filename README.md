# Weekend Bytes

A food ordering iOS app built with SwiftUI and Firebase as a school programming project.
Users/Customers can browse a menu of hotdogs, burgers and fries, check weekend promos,
choose a delivery address, and review their past orders.

## Features

- **Authentication:** email/password sign-up and login, Google Sign-In, and password reset
- **Menu:** items grouped by category (Hotdogs, Fries, Burgers and Drinks)
- **Promos:** weekly deals with a detail page for each
- **Cart and checkout:** add items, adjust quantities, and place an order
- **Delivery:** map-based address selection (MapKit)
- **Addresses:** save, edit and delete multiple delivery addresses
- **Payment entry:** GCash payment screen
- **Order history:** view past orders
- **Profile:** edit profile details, upload a profile photo, view badges, and delete your account
